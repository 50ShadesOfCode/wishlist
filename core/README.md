# core

Shared foundation for the Wishlist app: failures/exceptions, `UseCase` /
`StreamUseCase`, network info, storage (`HiveCacheService`, `OutboxService`,
`PrefsService`, `SecureStorageService`), app services (`ThemeController`,
`NotificationService`), and utils (id generation, logging, validators,
storage paths, constants).

Internal package (`publish_to: none`). See `wishlist_app/README.md` and
`AGENTS.md` (repo root) for the full picture.
